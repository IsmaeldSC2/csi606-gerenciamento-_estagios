# CSI606-2026-01 - Remoto - Proposta de Trabalho Final

Discente: Ismael dos Santos Costa (19.2.8190)

## Resumo

O presente trabalho tem como objetivo o desenvolvimento de um sistema web para gerenciamento de estágios, com foco na centralização de informações relacionadas a oportunidades de estágio, candidaturas e acompanhamento do processo pelos alunos.

Atualmente, muitas oportunidades de estágio são divulgadas por diferentes meios, como e-mails, grupos de mensagens e avisos informais, dificultando o acesso e o acompanhamento pelos estudantes. O sistema proposto busca organizar essas informações em uma plataforma única, permitindo o cadastro de vagas, consulta por estudantes e gerenciamento das candidaturas.

A aplicação terá interface web e persistência em banco de dados, permitindo o armazenamento e a manipulação das informações de forma estruturada.



## 1. Tema

O trabalho final tem como tema o desenvolvimento de um sistema web para gerenciamento de estágios acadêmicos, visando facilitar a divulgação, consulta e acompanhamento de oportunidades de estágio por alunos.



## 2. Escopo

Este projeto terá as seguintes funcionalidades:

- Cadastro de usuários (alunos e administradores);
- Autenticação de usuários;
- Cadastro de vagas de estágio;
- Consulta e listagem de vagas disponíveis;
- Filtro de vagas por área e empresa;
- Registro de candidatura do aluno;
- Visualização do histórico de candidaturas;
- Atualização do status das vagas;
- Gerenciamento de informações de empresas parceiras.



## 3. Restrições

Neste trabalho não serão considerados:

- Integração com sistemas institucionais externos;
- Assinatura digital de documentos;
- Geração automática de contratos;
- Controle jurídico do processo de estágio;
- Aplicativo mobile;
- Sistema de notificações em tempo real;
- Integração com e-mail institucional.



## 4. Protótipo

Protótipos para as páginas foram elaborados contemplando:

- Tela inicial;
- Tela de login;
- Cadastro de usuário;
- Listagem de vagas;
- Cadastro de vagas;
- Página de candidatura;
- Histórico de candidaturas;
- Painel administrativo.

Os protótipos das páginas serão desenvolvidos durante a execução do projeto e apresentados juntamente às etapas de implementação.
